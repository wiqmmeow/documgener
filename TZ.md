# ТЗ: плагин documgener для VS Code

1. Назначение: автоматическое создание Doxygen-комментариев для функций C++.
2. Запуск: команда "documgener: Generate Doxygen comment" и горячая клавиша Ctrl+Alt+D.
3. Вход: курсор стоит на первой строке сигнатуры функции.
4. Что делает плагин:
   - разбирает сигнатуру (тип результата, имя, параметры);
   - определяет направление параметра ([in] или [in,out]);
   - вставляет комментарий над функцией с сохранением отступа.
5. Особенности: поддержка шаблонных типов (std::vector<int>), ссылок, указателей, значений по умолчанию, сигнатур на нескольких строках.
6. Ошибки: если функция не найдена, показать понятное сообщение.
7. Ограничения: не поддерживает шаблоны функций (template<...>) и лямбды.
8. Технологии: TypeScript, VS Code Extension API, Node.js
