# Документация documgener

## Назначение
Плагин для VS Code, который по сигнатуре функции C++ создаёт Doxygen-комментарий.

## Структура проекта
- package.json: описание плагина, команда documgener.generate и горячая клавиша Ctrl+Alt+D.
- src/extension.ts: связь с VS Code. Читает строки из редактора, показывает сообщения и вставляет комментарий.
- src/parser.ts: разбор сигнатуры функции (splitParams, parseParam, parseFunction) и сборка комментария (buildComment).
- docs/: автоматически сгенерированная документация по комментариям в коде (typedoc).

## Используемые технологии
- Язык: TypeScript (компилируется в JavaScript).
- Платформа: Node.js, на нём запускаются плагины VS Code.
- Сборка: `npm run compile`, результат попадает в папку `out`.
- Документация: typedoc.

## Как запустить
1. `npm install` - устанавливает необходимые зависимости.
2. `npm run compile` - компилирует проект (превращает TypeScript в JavaScript в папке `out`).
3. Запустить тестовое окно: `code --extensionDevelopmentPath="C:\Users\Asus\Desktop\ISRPO_lab3\documgener"`
4. В тестовом окне открыть C++ файл, поставить курсор на строку с функцией и нажать Ctrl+Alt+D.

## Как работает разбор
Плагин берёт до 6 строк от курсора, пока не встретит `{` или `;`. Затем делит параметры по запятым (не трогая запятые внутри `<>`), отделяет тип от имени и по `const`, `&` и `*` определяет, входной это параметр или изменяемый. Из результата собирается комментарий с сохранением отступа.

## Как обновить автодокументацию
Если изменился код, выполнить: npx typedoc --plugin typedoc-plugin-markdown --entryPoints src/parser.ts src/extension.ts --out docs
