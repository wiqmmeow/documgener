# documgener

Плагин для VS Code, который генерирует Doxygen-комментарии для функций C++.

**Автор:** Усманова Аша Маратовна, группа M3115

## Возможности
- генерация @brief, @param, @return по сигнатуре функции
- определение направления параметра ([in] / [in,out])
- поддержка шаблонных типов, ссылок, указателей, значений по умолчанию
- сигнатуры на нескольких строках
- понятное сообщение, если на строке нет функции

## Использование
Поставьте курсор на строку с функцией и нажмите Ctrl+Alt+D.

## Запуск
`npm install`, `npm run compile`, затем открыть тестовое окно:
`code --extensionDevelopmentPath="путь к папке проекта"`

Язык: TypeScript. Платформа: VS Code Extension API (Node.js).

Документация: `DOCUMENTATION.md` и папка `docs/`.
